**Sistema de Gestión de Pacientes en un Hospital**

Este proyecto es una aplicación de consola desarrollada en Java que simula un sistema de triaje y gestión hospitalaria. Permite registrar pacientes, asignar médicos, gestionar consultas y atender a los pacientes por orden de prioridad a través de un menú de opciones.

**Características:**
Registro de pacientes con datos personales.

Registro del motivo de consulta y síntomas.

Asignación automática de número de atención.

Priorización de pacientes mediante una cola de prioridad basada en el nivel de triaje.

Asignación de pacientes a personal médico disponible.

Atención de pacientes en orden de prioridad.

Consulta del historial del paciente.

Visualización del estado del personal médico.

**Tecnologías utilizadas:**

-Java

-Estructuras de datos: HashMap, ArrayList

-E/S por consola
